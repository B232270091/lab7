## Аппыг ажиллуулах

Репогийн үндсэн хавтсанд дараах командыг ажиллуулаад браузераар `http://localhost:3000` хаягийг нээнэ.

```sh
node app.js
```

`app.js` нь багшийн Lab 7-д өгсөн `app (1).rar` хавсралтын эх файл. Нэмэлт сан суулгах шаардлагагүй.
Апп өгөгдлөө санах ойд хадгалдаг. Согог бүрийг давтахын өмнө `Ctrl+C` дараад `node app.js`-ээр дахин асаавал анхны гурван номтой төлөвт орно.

## Дүгнэлт

Supermodel аяллаар хамгийн олон зөрүү илэрсэн.
Энэ аяллаар тоолуур, оны таслал, устгах товчны өнгө, нэмэх товчны бичвэр, хуучин холбоос, урт гарчгийн тэлэлтийг тэмдэглэсэн (BUG-01–04, BUG-10–11).
Couch Potato аяллаар хоосон талбар, буруу он, давхардсан номыг тус тус барилаа (BUG-05–07).
Fed-Ex-ээр өгөгдлийг нэмэхээс устгах хүртэл дагахад хайлтын том жижиг үсэг болон устгалын мессеж дээр зөрүү гарсан (BUG-08–09).
Saboteur аяллаар дутуу JSON илгээхэд `200 OK` ирж байгааг `curl`-ээр шалгасан (BUG-12).

Charter-аас гадуур Tab, Enter-ээр бөглөж үзэхэд хоосон зохиолчтой ном мөн нэмэгдсэн.
Дараагийн session-д Firefox дээр хайлтыг давтаж, жижиг дэлгэцэд урт өгөгдөлтэй хүснэгтийг гарын товчлуураар ашиглаж үзнэ.
Лаб 1-ийн Playwright тестэд мөрийн тоо, талбарын дүрэм, давхардал, хайлтын үр дүн, мессеж болон HTTP статусын шалгалт нэмбэл эдгээр зөрүүг автоматаар барьж болно.
Өнгө, таслал, хэвтээ тэлэлтийг дэлгэц дээр анзаарсан бөгөөд «Нэмэx»-ийн латин `x`-ийг тэмдэгтийн кодоор баталсан.
Эдгээр харагдацын зөрүүг барихад зураг, CSS шинж болон товчны яг бичвэрийг тусад нь шалгах хэрэгтэй.
